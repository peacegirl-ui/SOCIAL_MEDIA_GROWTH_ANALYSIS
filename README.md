# 📊 Social Media Growth Analysis

## 📌 Project Overview

This project analyzes social media performance data to identify engagement trends, audience behavior, and content performance across different platforms.

The goal is to understand which platforms, content types, and audience segments generate the highest engagement and reach, helping businesses make better data-driven marketing decisions.

## 🛠️ Tools & Technologies

- Python – Data Cleaning & Exploratory Data Analysis
- SQL – Data Analysis & Business Queries
- Power BI – Interactive Dashboard & Visualization
- Excel – Dataset

## 📈 Dashboard Preview

![Social Media Growth Analysis Dashboard](Social%20Media%20Dashboard.png)

## 🔍 Key Insights

- Instagram generated the highest total engagements.
- Facebook recorded the highest average engagement rate.
- Reels showed strong engagement and reach performance.
- Audience age groups and countries were analyzed to understand engagement behavior.
- Content types were compared to identify better-performing posts.

## 📂 Project Files

- Python Notebook – Data Cleaning & Analysis
- SQL File – Business Analysis Queries
- Power BI Dashboard – Interactive Visualizations
- Dataset – Social Media Performance Data

## 🎯 Project Objective

To analyze social media growth and performance using Python, SQL, and Power BI, and provide meaningful insights for improving digital marketing strategies.
